# Arquivos-fonte

- `textures/`: PSD, EXR, PNG ou outros arquivos editáveis.
- `screenshots/`: comparações antes/depois feitas dentro do jogo.
- `notes/`: medições, valores testados e decisões de calibração.
- `skybox/`: panoramas, máscaras e arquivos intermediários para conversão SCS.
- `skybox-analysis/`: prévias temporárias usadas para comparar formatos oficiais.
- `baseline/`: definições oficiais preservadas para reconstruções reproduzíveis.

Nada desta pasta deve ser incluído no pacote `.scs`.
